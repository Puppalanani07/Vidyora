# Vidyora

Vidyora is an AI learning assistant backend built with Python and Flask.

## Run on Windows with PowerShell

Open PowerShell in the project directory and create and activate a virtual environment:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks script activation, allow it for the current process and retry:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

Install the dependencies and create a local `.env` file from the example:

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
```

Set `GROQ_API_KEY` in `.env` to your Groq API key to enable generated tutor responses. The server prints an error at startup if the key is missing. Keep keys in this backend-only `.env` file; do not put them in frontend code or commit `.env`. The `.gitignore` excludes `.env` and `.venv`.

Start the chat API (debug mode is enabled for local development):

```powershell
python app.py
```

The server listens at `http://127.0.0.1:5000`.

Install `Flask-Cors` from `requirements.txt`; the API allows the Live Server origins
`http://127.0.0.1:5500` and `http://localhost:5500`.

## Health check

With the server running, open a second PowerShell window and request the liveness endpoint:

```powershell
Invoke-RestMethod http://127.0.0.1:5000/health
```

The endpoint returns:

```json
{
  "status": "ok"
}
```

## Frontend

Start the API with `python app.py`. To use VS Code Live Server, open `frontend/index.html`, choose **Open with Live Server**, and load the page from its localhost URL (usually `http://127.0.0.1:5500` or `http://localhost:5500`). Flask CORS is enabled. The frontend sends chat requests to `http://127.0.0.1:5000/chat`.

The frontend sidebar also includes History and Create Images/Create Videos pages. Image and video generation are placeholders. The simple `/chat` API does not save conversations, so chat history is unavailable when running `app.py`.

The chat UI sends `message` and `level` to `POST /chat`. Example PowerShell request:

```powershell
$body = @{
    message = "Why do seasons change?"
    level = "Beginner"
} | ConvertTo-Json

Invoke-RestMethod -Method Post `
  -Uri http://127.0.0.1:5000/chat `
  -ContentType "application/json" `
  -Body $body
```

The response contains a `reply` generated by Groq using `openai/gpt-oss-120b`. Invalid requests return HTTP 400; unexpected API failures return a JSON error. The backend never returns the API key.
